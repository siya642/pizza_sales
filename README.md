# 🍕 Pizza Sales Analysis | SQL & Power BI


## 📌 Project Overview

This project focuses on analyzing pizza sales data using **SQL and Microsoft Power BI** to uncover meaningful business insights and understand sales performance.

SQL is used to explore the sales data, answer business questions, and analyze key performance indicators (KPIs). Power BI is used to transform the analysis into an interactive dashboard with multiple report pages and button-based navigation.

The goal is to turn raw sales data into meaningful insights that can help businesses understand customer ordering patterns, product performance, and revenue trends.

## 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Calculate important sales KPIs.
- Identify top-performing and low-performing pizzas.
- Understand daily and monthly sales trends.
- Analyze customer ordering patterns by day and hour.
- Compare pizza categories and sizes.
- Build an interactive Power BI dashboard.
- Improve dashboard usability through navigation buttons.
- Present business insights in a clear and visual format.

## 🗄️ Part 1: SQL Sales Analysis

SQL is used to investigate the pizza sales dataset and answer business-related questions through structured queries.

### Key Areas of Analysis

**1. Key Performance Indicators (KPIs)**

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order

**2. Time-Based Analysis**

- Monthly revenue trends
- Daily order distribution
- Orders by hour of the day
- Identification of peak ordering periods

**3. Product Performance Analysis**

- Best-selling pizzas by quantity
- Revenue contribution by pizza
- Top-performing and low-performing products
- Sales comparison across pizza categories

**4. Category and Size Analysis**

- Revenue by pizza category
- Quantity sold by category
- Sales distribution by pizza size
- Comparison of product performance

### SQL Concepts

The analysis may involve the following SQL concepts, depending on the queries implemented:

- `SELECT` and `WHERE`
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` and `ORDER BY`
- Date and time functions
- `CASE` statements
- Joins and subqueries, where required
- Common Table Expressions (CTEs) and window functions, where applicable

## 📊 Part 2: Power BI Dashboard

The Power BI dashboard presents the pizza sales analysis through interactive visualizations, KPI cards, and multiple report pages.

### Dashboard Features

**1. KPI Cards**

Provides a quick overview of important business metrics, including revenue, orders, pizzas sold, and average order value.

**2. Sales Trend Analysis**

Visualizes sales performance over time to help identify trends and variations in demand.

**3. Daily and Hourly Analysis**

Explores order patterns across different days of the week and hours of the day.

**4. Pizza Performance Analysis**

Helps compare products and identify pizzas contributing most to overall sales.

**5. Category and Size Analysis**

Presents sales performance across pizza categories and sizes.

**6. Interactive Page Navigation**

Uses **button-based navigation** to let users move between different dashboard pages with a simple click.

This creates a more organized, intuitive, and user-friendly reporting experience.

**7. Interactive Visualizations**

Allows users to explore sales data through report visuals and filters, where configured.
